# Simple_Calculator
🧮 3D Calculator

A modern and interactive 3D Calculator developed using **HTML, CSS, and JavaScript**. The calculator provides a clean neon-style interface with 3D button effects and supports basic mathematical operations.

✨ Features

Addition, subtraction, multiplication, and division

Power (^) operation

Decimal number support

Clear (AC) functionality

Delete (DEL) functionality

Interactive 3D button effects

Responsive and user-friendly interface

Neon-themed design

🛠️ Technologies

HTML5 – Structure

CSS3 – Styling and 3D effects

JavaScript – Calculator functionality

📁 Project Structure

3D-Calculator/

├── index.html

├── style.css

├── script.js

└── README.md

🚀 How to Run

Clone or download the repository.

Open the project folder.

Open index.html in any modern web browser.

Use the calculator to perform mathematical operations.

🎯 Purpose

This project was created to practice and demonstrate fundamental frontend web development concepts, including HTML structure, CSS styling, and JavaScript functionality.
